# API Gateway

## Traefik

Решаемые задачи:
- Авторизация / аутентификация
- Маршрутизация по сервисам
- Создание TraceId для логирования
- Балансировка запросов
- rate limiter и circut breaker для запросов от пользователей
- Вызовы от внешних систем - rate limiter для них

Обоснование: Traefik был выбран, так как легко разворачивается в k8s среде как ингресс сервис. Из коробки решает много задач и доступны плагины. Достаточно легковесный. Легко масштабируем, так как стейтлэс в памяти. Из минусов - экосистема меньше, чем у Kong, но в данном случае не критично, так как покрывает пул задач.
