# Bounded Context

## Customer BC
Функционал: 
- Работа с личными данными пользователей

Термины:
- Пользователь - клиент банка(физ лицо)

Исходящие связи:
- Auth BC - регистрация пользователя

## Auth BC
Функционал: 
- Регистрация пользователей
- Аутентификация пользователей
- Авторизация пользователей

Термины:
- Пользователь - клиенты банка(физ лица и мерчанты)

## Wallet BC
Функционал: 
- Данные о счете пользователя
- Работа с балансом
- Пополнение счета
- Блокировка счета
- Создание счета и привязка к пользователю

Термины:
- Пользователь - клиент банка
- Счет - привязанная к пользователю карта
- Баланс - кол-во денег на счете
- Операции - операции по изменению баланса на счете
- блокировка счета - ограничение доступа пользователю к его счету

Исходящие связи:
- Customer BC - привязка счета к клиенту

## Payments BC
Функционал: 
- Создание и обработка платежа
- Перевод денег на другой счет
- Обработка запросов от мерчантов

Термины:
- Платеж - Оплата внещних покупок с изменением баланса счета
- Счет - привязанная к пользователю карта

Исходящие связи:
- Core Banking BC - отправка информации о платеже для ведения бух учета
- Merchant BC - отправка callback об операции мерчанту
- Anti-Fraud / Scoring BC - проверка операции на мошенническую
- Notifications BC - отправка уведомления об операции клиенту
- Wallet BC - изменение баланса на счету при транзакции

## Core Banking BC
Функционал: 
- Обеспечение консистентности баланса

Термины:
- Баланс - кол-во денег на счете

## Notifications BC
Функционал: 
- Отправка email уведомлений пользователям

## Anti-Fraud / Scoring BC
Функционал: 
- Проверка операций на мошенничество
- Определение скоринга риска
- блокировка счета

Термины:
- Операция - переводы межды счетами
- Скоринг риска - показатель мошеннической операции

## Merchant BC
Функционал:
- Работа с данными пользователя
- Установка callback url
- Отправка callback о платежах пользователю

Термины:
- Пользователи - мерчанты(продавец товаров или услуг)

Исходящие связи:
- Auth BC - регистрация пользователя
