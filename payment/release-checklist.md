# Чеклист релиза по безопасности
 - секреты не захардкожены
 - секреты не хранятся в обычных env
 - mTls включен
 - HMAC на провайдере работает корректно
 - API endpoints защищены AuthN/AuthZ
 - JWT пользователей не хранится на фронте
 - во внутренние сервисы пробрасывать exchange token
 - миграции бд выполняются корректно
 - работает функционал feature flag
 - canary deploy отрабатывает
 - canary deploy поддерживает rollback по SLI
