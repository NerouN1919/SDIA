# Observability: метрики, логи, трейсы, SLI/SLO

## Наблюдаемость
Будут собираться следующие метрики:
- API Gateway - RPS в целом
- Wallet - Saturation, процент ошибок(5xx), latency
- Transaction - Saturation, процент неуспешных созданий платежей, latency
- Callback - Saturation, процент дублей callback-ов
- Query - Saturation, latency
- Payment Provider - latency, процент неуспешных вызовов(5хх)
- Broker - offset lags, размер очередей

Для наблидаемость используем:
- Prometheus и Grafana для сбора, хранения и отображения метрик
- Loki + Grafana Alloy + Grafana для сбора, хранения и визуализации логов
- OpenTelemetry + Tempo + Grafana для сбора, хранения и визуализации трейсов

## SLI/SLO
1. SLI: процент успешных запросов на создание платежа(не 5хх) от общего числа запросов  
SLO: 99.9% успешных запросов за 30 дней
2. SLI: p99 - Скорость обработки платежа: От получения события до проставления успешного статуса  
SLO: не превышает 45 секунд за 30 дней
3. SLI: Доля сообщений в топике payment.initiated, попавших в DLQ от общего числа обработанных сообщений(закомиченный оффсет)
SLO: DLQ rate < 0.1% за 24 часа  

| SLI | SLO | Где меряем |
|---|---|---|
| процент успешных запросов на создание платежа(не 5хх) от общего числа запросов | >= 99.9% за 30 дней | Metrics Wallet Service |
| p99 - Скорость обработки платежа: От получения события до проставления успешного статуса | <= 45 сек за 30 дней| Metrics Transaction Service |
| Доля сообщений в топике payment.initiated, попавших в DLQ от общего числа обработанных сообщений(закомиченный оффсет) | DLQ rate < 0.1% за 24 часа | Kafka |

## Дашборды

### Business Dashboard
Дашборд для менеджмента, не включает в себя особо технических деталей
- Процент успеха инициализации платежа
- Процент успеха обработки платежа
- RPS приложения
- Latency платёжного провайдера

### Developers Dashboard
Дашборд для разработчиков, системных аналитиктов и девопсов, показываюзий узкие места микросервисов и информацию о них
- Saturation по каждому микросервису
- Процент ошибок на каждом микросервисе
- Latency по микросервисам
- Информация о брокере(лаг и размер топика)
- процент дублей от платёжного провайдера
