# Webhook Security

Проверка HMAC от внешнего провайдера происходит на уровне API Gateway  
Подписываются:
- тело запроса
- eventId
- timestamp

Используемые заголовки:
- X-Signature
- X-Timestamp
- eventId

На стороне API Gateway высчитывается HMAC, сверяется с X-Signature. Также проверяется время относительно X-Timestamp по TTL(5 минут).
Для защиты от replay используется временная метка и eventId. Обработанные записи мы сохраняем в Replay Store(TTL 5 минут) с eventId и при каждом запросе смотрим, нет ли там данных. Если данные есть, то это запрос дубль и мы возвращаем 200 код без обработки

Идемпотентность также реализована на стороне Callback Service - там мы сверяем id от провайдера и проверяем на дубль
