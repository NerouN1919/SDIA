# Secrets

Secrets:
- Пароли от БД
- client_id и client_secret для Keycloak
- приватные ключи mTLS
- provider API key
- webhook signing secret

На dev окружении для уменьшения трудозатрат развертывания секреты могут хранится в k8s secrets
Для prod окружения используем Vault для более надежного хранения с шифрованием

Сервис получает креды с помощию Vault Agent sidecar  
Для аутентификации Vault используем K8s auth  

При изменении webhook на новый мы принимаем старый и новый до тех пор, пока остались необработанные запросы со старым, после переходим только на новый.  
provider api key можем сразу заменять на новый без сохранения старого
